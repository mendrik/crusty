# Research through an attached agent with human promotion

The restriction against GitHub delivery integration is superseded by [ADR 0006](0006-coordinate-sessions-and-github-delivery.md) at the owner's explicit request. The research and finding-promotion policy below remains applicable to autonomous source gathering.

Crusty performs bounded local discovery, then hands a research packet to the attached agent for primary-first web search instead of embedding web, GitHub, telemetry, or product-management connectors. Submitted technical, product, and design findings remain proposals: only a named human review can accept them, and a second explicit confirmation promotes one into project work. This keeps research current and useful without letting external material or autonomous reasoning silently become backlog authority.
